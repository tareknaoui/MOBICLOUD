// MOCKUP MOBICLOUD v5

Mis à jour après implémentation Story 13.3 (Annulation upload/download). Reflète exactement le comportement du code Kotlin/Compose.

// TÉLÉPHONES DANS CE MOCKUP

1 — PermissionsScreen : onboarding premier lancement.

2 — InitScreen : initialisation P2P animée.

3 — App principale : Dashboard / Fichiers / Communauté / Paramètres. Onglet Fichiers : TopAppBar + swipe (cliquer 1re carte).

4 — TrashScreen (non vide) : liste corbeille avec date + jours restants.

5 — TrashScreen (vide) : état vide.

6 — Upload en cours : ErasureProgressIndicator état Distributing + bouton "✕ Annuler" + snackbar "Upload en cours".

7 — Upload annulé : StoreState.Cancelled → "⊘ Upload annulé" (3s puis Idle).

8 — Download en cours : DownloadProgressIndicator état Downloading + bouton "✕ Annuler".

// PARCOURS PREMIER LANCEMENT

PermissionsScreen → InitScreen → Dashboard. Pas de bottom nav pendant l'onboarding (currentTopLevelDestination = null).

// CE QUI A CHANGÉ (v4→v5 — Story 13.3)

new StoreState.Cancelled — état dédié, visible 3s puis retour à Idle.

new cancelUpload() — annule storeJob + resetJob, émet Cancelled, scheduleReset(3s). Le finally { tempFile.delete() } s'exécute toujours.

new Bouton "✕ Annuler" dans ErasureProgressIndicator — visible quel que soit le sous-état (Encoding/Encrypting/Distributing).

new Bouton "✕ Annuler" dans DownloadProgressIndicator — câblé sur resetDownloadState() existant (cancelle locateJob + downloadJob).

new Snackbar "Upload en cours" — via uploadBusyEvent: SharedFlow<Unit> quand 2e upload tenté pendant InProgress.

new storeJob: Job? — tracke la coroutine d'upload, pattern identique à downloadJob.

new scheduleReset(delayMs) — paramètre optionnel, 5s par défaut (inchangé pour Success/Error), 3s pour Cancelled.

// CE QUI A CHANGÉ (v3→v4 — Story 13.2)

new TopAppBar "Mes fichiers" — titre + icône 🗑 amber en haut à droite → navigue vers TrashScreen.

new SwipeToDismissBox — balayage vers la gauche sur une fiche = soft-delete (fond rouge, icône 🗑). Cliquer la 1re carte pour simuler.

new Snackbar "Déplacé vers la corbeille" + bouton "Annuler" (5s) → restoreFromTrash().

new TrashScreen — liste avec originalFileName, date suppression, jours restants (TTL 30j), boutons Restaurer (amber) + Supprimer définitivement (rouge).

new Dialogues de confirmation — "Supprimer définitivement ?" et "Vider la corbeille ?" avec bouton destructif rouge.

new Purge TTL automatique — au lancement de l'Explorateur, les entrées > 30j sont supprimées définitivement.

new Migration Room v17→v18 — colonnes is_in_trash + deleted_at sur catalog_entry.

// FONCTIONNEMENT DU MOCKUP

Bouton Mode en haut à droite : bascule Simple ↔ Expert.

Sur le téléphone 3, onglets : Fichiers · Mon Nœud · Communauté. Icône ⚙ → Paramètres.
