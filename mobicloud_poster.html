Introduction & Problem Statement

Global data volumes are growing exponentially, yet traditional cloud storage relies on costly, centralized infrastructures that compromise user privacy and data sovereignty. Smartphones collectively hold considerable storage capacity that remains largely unused. MobiCloud turns this idle capacity into a secure, resilient, peer-to-peer distributed storage network.

Methodology & System Design
Legend: SP = elected Super-Peer  ·  small nodes = regular peers  ·  dashed circle = cluster boundary  ·  solid lines to center = relay signaling channel

Devices self-organize into clusters, each coordinated by a dynamically elected Super-Peer (Bully algorithm, weighted on battery / uptime / signal reliability). Files are erasure-coded (Reed-Solomon k=3, n=2) and encrypted (AES-256-GCM) before fragments are distributed across cluster members. The relay server only handles signaling and NAT traversal — it never accesses unencrypted data.

Results and discussion

Storage Efficiency

Reed-Solomon erasure coding (k=3, n=2) reconstructs files using only 1.67× the original size — versus 3× for full replication — while tolerating the loss of any 2 fragments.

Resilience & Failover

Under simulated churn, Bully-based Super-Peer election consistently elected a new coordinator in under 6 seconds. The cluster remained stable with up to 30% of nodes leaving simultaneously.

Security Validation

Peer identities are bound to hardware-backed keys (Android Keystore/TEE, secp256r1). Fragments are individually encrypted (AES-256-GCM) and every protocol message is ECDSA-signed with replay protection.

Real-Device Testing

The prototype was validated on physical clusters of 3-5 Android devices (Pixel 6/7, Galaxy S21) across 4G and Wi-Fi networks, confirming successful discovery, erasure-coded transfer, and cluster failover.

Conclusion

This project delivered a working mobile-native distributed storage system that replaces centralized cloud infrastructure with a self-organizing cluster of smartphones. Erasure coding, hardware-backed cryptography, and Bully-elected Super-Peer coordination together provide resilient, storage-efficient, privacy-preserving storage — validated on real Android hardware. Results confirm the approach's viability and open the way toward removing the remaining relay server for full decentralization.
